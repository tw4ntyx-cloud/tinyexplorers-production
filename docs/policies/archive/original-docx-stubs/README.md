# Original Word stubs (archived 2026-10-19)

These eleven `.docx` files were in `frontend/public/policies-docs/`, so they could be downloaded from the website by URL, although nothing linked to them. Each contained only 0–4 of the policy's text blocks (for example, the Enrollment Policy stub had 0 of 18). They were incomplete placeholders, not approved documents.

They are kept here unchanged for reference. Complete editable copies, generated from the published v1.0 policy text (which matches the approved PDFs word for word), are in `../../docx/`.

The approved, published versions remain the PDFs in `frontend/public/policies-docs/`.
