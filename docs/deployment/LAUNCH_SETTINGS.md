# Launch settings (domain cutover, C3)

_Prepared 2026-11-12. **Nothing here is applied.** Launch needs the owners' signed Launch Authorization and a separate go-ahead._

The site no longer needs file edits to move to the real domain. These files are generated by `frontend/scripts/site-files.js` after every `npm run build`, from the settings below:
- `robots.txt`
- `sitemap.xml`
- the GitHub Pages `404.html`

## Frontend build settings

| Setting | Preview (today) | Launch |
|---|---|---|
| `PUBLIC_URL` | unset → `/tinyexplorers-production` (from `package.json` `homepage`) | `/` |
| `REACT_APP_WEBSITE_URL` | `https://tw4ntyx-cloud.github.io` | `https://tinyexplorersbda.com` |
| `REACT_APP_ROBOTS` | `noindex, nofollow` | `index, follow` |
| `REACT_APP_BACKEND_URL` | Cloud Run URL | the production API URL (unchanged unless the API moves) |
| `REACT_APP_TOUR_BOOKING_URL` | Google Calendar booking page | unchanged |

Set these as the host's build environment variables (e.g. Cloudflare Pages / Vercel project settings). Real environment variables take precedence over `.env.production`.

**Verified on 2026-11-12** with a local launch build:
- `<meta name="robots" content="index, follow">`;
- assets served from `/static/…`;
- sitemap and robots point at `https://tinyexplorersbda.com`;
- `404.html` uses `segmentCount = 0`;
- no `github.io` references remain.

## Backend settings (Cloud Run)

| Variable | Launch value |
|---|---|
| `WEBSITE_URL` | `https://tinyexplorersbda.com` (used in email links, including the newsletter unsubscribe link) |
| `CORS_ORIGINS` | `https://tinyexplorersbda.com` (plus `https://www.tinyexplorersbda.com` if used) |

## Still manual at launch

- DNS and HTTPS for the domain at the chosen host.
- Single-page-app rewrites: on Cloudflare Pages or Vercel, use the host's rewrite rule (`frontend/vercel.json` already has one). `404.html` is only needed on GitHub Pages.
- `deploy-gh-pages.yml` asserts the preview paths. Retire or update it when the preview is retired.
- Submit `https://tinyexplorersbda.com/sitemap.xml` in Google Search Console.

## Private staging copy

`.devcontainer/start-staging.sh` builds this branch with production settings (root path, never indexed) and serves it on port 4000. The API runs in safe mode: no database, no email, no Google Workspace. It is the place to review changes before any real staging or launch.
